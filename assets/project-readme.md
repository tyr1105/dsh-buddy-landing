# 队友：DSH 版 Grok Bot

在 DeepSeek Harness（DSH）里养几个常驻的 AI 队友。每个队友有名字、有分工、有自己的长期志向；它们会自己盯着你指给它们的东西，**有理由才动脑**，想完自己决定下次什么时候再看；需要你拍板时，才在对话线程里找你。你从不需要给它们设闹钟。

## 它和「定时任务」有什么不一样

| | 定时任务（闹钟式） | 队友（主动式） |
|---|---|---|
| 什么时候干活 | 你定的时间一到就跑 | 它盯的东西有了变化、它答应你的事到期、某个目标停滞太久，才醒来想一次 |
| 没事的时候 | 照样调用一次模型，回你一句「没事」 | 不调用模型，不花额度 |
| 下次什么时候 | 固定 | 它自己约（只能约下一次，并写明理由），中心按上下限夹住 |
| 找你 | 到点就汇报 | 日常的事攒进每天 08:30 的日报；只有提问、审批、出问题才单独提醒你，免打扰时段（23:00–08:00）不推送 |

## 安装（一次性）

1. 完全退出 DeepSeek Harness（菜单栏 → 退出）。
2. 在终端运行 `bash ~/.agent-hub/install.sh`（它会先构建插件，再用桌面版自带的命令把插件装进 desktop 档位）。
3. 重新打开 DeepSeek Harness，左侧栏会出现「队友」。

卸载同理：退出 DSH → 运行 `bash ~/.agent-hub/uninstall.sh` → 重新打开。你的队友数据保留在 `~/AgentHub`，不会被删。

## 怎么用

- **新建队友**：点右上角「新建队友」，6 步：名字与角色 → 性格与说话风格 → 志向 → 自主等级与节奏 → 起步要盯的东西（可跳过）→ 确认上岗。上岗后它会先「试跑」：在线程里向你做自我介绍，并给自己搭好要盯的东西和待办。
- **四种角色**：总管（统筹全队、分派与跟进，最多 1 个）、调研（盯信息源、做研究、写结论）、执行（把事情做完，按规矩交付）、盯守（盯运行记录与期望，异常就报）。
- **和它说话**：左边选一个队友，在下方输入框打字，回车发送，它会尽快醒来回复你。「团队」线程里的话默认交给总管；用 @名字 可以点名。
- **处理它的请求**：提问、审批、提议会以卡片形式出现在它的线程里和「收件箱」里，点按钮即可。
- **教它一招**：你在 DSH 里亲手做过一件事，可以在它的线程头部点「教它一招」，选那个会话，它会读一遍过程，写成自己的「套路」，以后照做；你可以在右栏修改套路。
- **看它为什么醒、为什么没醒**：右栏最下方「为什么醒 / 为什么没醒」逐条列出每次判断的理由与分数。
- **看它到底干了什么**：线程头部「打开工作会话」跳到它在 DSH 里的工作会话，能看到每一步工具调用。
- **让它盯「该按时发生的事」**：对它说「盯一下 ~/Library/Logs/xxx/paper-morning.out.log，工作日每天 08:20 前应该有新内容」。它会建一个带期望的关注项（试岗期是「提议」，你在卡片上点接受才生效）。期望可以只在工作日或指定星期检查，周末不误报；没按时出现，它会被叫醒并告诉你，第二天日报里也会写【未出现】。
- **打断它**：它正在处理时，线程头部有「打断」（点两次确认）。打断不算它的错，它下次醒来会接着处理。
- **审批**：它要做别人看得见或不可逆的事（发网络请求、写家目录外的文件、跑有风险的命令）时，会发一张审批卡，用大白话写清楚要做什么、目标是什么；你批准后由中心代为执行一次，结果写回线程。

## 安全边界（它能做什么、不能做什么）

- **自主等级**：L0 只观察 / L1 建议（新队友试岗 7 天一律按 L1）/ L2 执行 / L3 授权执行（只能你手动设）。
- **四类动作**：A 内部可撤销（直接做）、B 改自己的关注与议程（按等级）、C 别人看得见或碰真实数据（要你批准）、D 不可逆或高风险（L1 起都要你批准，L0 直接拒绝，例如删除家目录外的文件、强推代码、付款下单）。批准只对那一个具体动作有效一次。
- **它碰不到的**：DSH 的沙箱只允许它写自己的家目录 `~/AgentHub/bots/<它的编号>/`；工具参数或命令里写明的名单内凭据路径（`~/.dsh`、`~/.ssh`、`.env` 等）会被拦下；提问后干等、派子代理、设定时提醒等会挂住或绕过管控的工具已被禁用。
- **已知缺口**：动作闸只看得到工具参数和命令里写明的内容。名单外的文件、递归搜索、家目录脚本内部的读取和联网还拦不住；HTTP GET 算只读、直接放行，内容可以放进网址带出去。队友还能把自己家目录里的脚本交给中心运行：这一步不用批准，也不受 DSH 沙箱限制，能改动这台电脑上的其他文件，线程里看不到。所以暂时不要让队友读陌生网页这类不可信的内容。
- **额度**：每 5 小时窗口全队起步最多 8 个回合，第一次遇到额度报错后，按当时用量的 90% 校准；每个队友每天有回合和 token 上限；额度紧张时自动放慢，用尽时全体歇着、窗口恢复后先放一个「探针」试水。注意：中心看不到你自己用了多少，所以不能保证给你留出固定比例。
- **一键停用（不卸载）**：在 `~/AgentHub/.hub/` 里新建一个名为 `DISABLED` 的空文件，重启 DSH 后引擎停用、只留界面；删掉这个文件再重启即恢复。

## 已知限制（v1）

- DSH 开着、电脑醒着，队友才在岗；DSH 停了再开，它们会「补课」并告诉你停了多久。
- 队友自己建的关注项 30 天后自动失效，不会提醒你，到时要再让它加一次。
- 中心代为运行的命令只等 30 秒，超时会被停掉并报失败，不适合长任务。
- 关注的日志每次更新也算一条小变化，攒够两条队友会工作一次，这也花额度。
- 还不能代你登录任意网站操作（浏览器自动化）、没有手机端、没有接飞书或邮件。这些在后续版本里。
- DSH 是预发布版，接口可能随升级变化；插件只声明支持 0.2.x，DSH 大版本升级后插件会自动停用，需要更新插件。

## 给开发者

- 代码结构、实现规格、任务卡与验收记录：`docs/build-spec.md`、`docs/tasks/`、`docs/progress/`、`docs/reviews/`。

- 界面走查：`bash scripts/dev/ui-sandbox.sh`（浏览器里点的沙箱 + 走查专用假模型，用法见 `scripts/README.md`）。
- 设计资料（PRD、Grok Bot 功能清单、DSH 插件开发手册、可行性与证据）：`docs/design/`。
